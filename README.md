# Fundação Kirongozi

Site institucional da Fundação Kirongozi, publicado automaticamente no GitHub Pages.

## Estrutura

- `index.html` — conteúdo e estrutura semântica
- `style.css` — identidade visual e layout responsivo
- `script.js` — menu, animações, navegação ativa e progresso de leitura

## Desenvolvimento local

Abra `index.html` no navegador ou sirva a pasta com um servidor HTTP local.

## Publicação

Todo push na branch `main` aciona o workflow do GitHub Pages.
